# neoskills 编码规范

本文档是项目级补充规则，只记录与全局规则（`~/.claude/rules/common/coding-style.md`）不同的或全局规则未覆盖的约束。全局规则中已有的不可变性、文件组织、错误处理、输入验证等要求在此不重复。

## 函数

- 用独立函数组织代码，不用状态型类
- 函数保持幂等：相同输入返回相同输出，不依赖隐式共享状态
- 用小函数组合代替继承层级
- 工具函数独立存放，不埋入状态型对象
- 只有"额外语义"才值得包装；单纯转发调用不算抽象
- 标准库或成熟库已解决的问题直接调用，不重新实现

## 模块

- 模块名直接表达职责，不用泛化名称（`utils`、`tools`、`common`）
- 默认值定义为模块级常量，不放散在函数体内
