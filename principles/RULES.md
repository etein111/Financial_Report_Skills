# AGENTS.md 编写规范

## 措辞

- 用"必须 / 不要 / 仅可 / 禁止"，不用"尽量 / 建议 / 注意 / 合理"
- 每条规则包含条件、对象、动作三要素
- 规则右侧写可观察的具体行为，不写抽象目标
- 用可计数的约束替代"优雅 / 简洁 / 合理 / 必要时"等主观判断
- 每条规则只约束一件事；多个约束拆成独立规则
- 不用"等等 / 之类 / 等类似"收尾
- 规则中不嵌入背景解释——背景放注释或独立段落

## 触发条件

- 用路径、操作类型、内容特征作为触发条件，不写无条件的泛化规则
- 无条件规则视为全局生效，不附加"当…时"
- 两条规则可能冲突时，用条件消歧
