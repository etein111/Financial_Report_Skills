# neolyst Skill 全局规则

整体长期规则与跨接口共享规则。实现细节见 `skills/neolyst/` 目录下的 README、代码注释和 references。

### 业务逻辑落点

业务数据一致性、状态流转、关系维护、主表/版本表同步的逻辑，均优先在 Supabase 侧实现为稳定接口。复杂读写（涉及路径规则、多表维护、跨表判断、校验+写入原子操作）默认在 Supabase 侧封装为 RPC，不在 skill 侧拼接多次底层表操作。`neolyst` skill 负责认证、文件上传、参数整理和调用 Supabase 接口，不重复实现核心业务一致性规则。不用外键，跨表一致性由 RPC 负责。

### 错误语义

所有接口失败时直接抛出具体错误，不做静默吞错或模糊提示。错误信息必须足够明确，让上游 LLM 或人工据此补字段、重新确认或中止流程。
