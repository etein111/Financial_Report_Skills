**问题 7：schema.yaml 需要哪些字段**

**用户反馈：设计太复杂**

**讨论结果：极简设计**

**只保留三个属性：**
- `name` - 字段标识
- `description` - 字段含义
- `format` - 格式示例（可选）

**不包含：**
- `required` - 这是运行时校验逻辑
- `type` - 第一版不需要强类型
- `version` - git 已管理
- `default` - 可在模板层面处理

```yaml

    description: 报告日期
```
