## Why

当前券商内部缺少一个统一的投资研究报告管理系统。研究报告的管理流程依赖手动操作,效率低下且容易出错。需要建立一个集中化的系统来管理报告的创建、编辑、版本控制、审核和发布流程。

## What Changes

构建一个基于 Web 的投资研究报告管理系统(第一个版本),包括:

**基础数据管理模块:**
- Analyst(分析师)信息管理
- Coverage(公司覆盖)信息管理
- Sector(行业分类)管理(两级结构)
- Region(地区)管理
- Word 模板文件管理

**报告管理模块:**
- 报告创建(基本信息 + Word 文档 + Excel 模型文件)
- 报告编辑(基本信息和文件)
- 版本管理(所有修改保留历史,记录修改人和时间)
- 报告发布(标记为已发布状态,记录发布时间)
- 报告拒绝(软删除)
- 未发布报告列表查看

**对外接口:**
- 提供已发布报告的查询 API,支持按时间戳增量查询,供外部系统集成

## Capabilities

### New Capabilities
- `基础数据管理`: 管理分析师、公司覆盖、行业分类、地区等基础数据
- `报告创建`: 创建新的研究报告,关联基础数据和上传文件
- `报告编辑`: 修改报告基本信息和文件
- `版本管理`: 追溯报告的所有修改历史,支持合规检查
- `报告发布流程`: 控制报告的发布和拒绝状态

## Impact

**数据库结构:**
- 新增 Analyst、Coverage、Sector、Region 表
- 新增 Report、ReportVersion、ReportFile 表
- 新增 WordTemplate 表

**后端 API:**
- FastAPI 服务,提供基础数据和报告管理的 RESTful API
- 集成 Supabase 认证和存储

**前端界面:**
- Vue 单页应用
- 基础数据管理页面(Analyst、Coverage、Sector、Region、模板)
- 报告管理页面(列表、创建、编辑、版本历史)
