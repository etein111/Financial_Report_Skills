## Why

建立一个集中化的系统来管理报告的创建、编辑、版本控制、审核和发布流程。

## What Changes

构建一个基于 Web 的投资研究报告管理系统(第一个版本),包括:

**基础数据管理模块:**
- Analyst(分析师)信息管理
- Coverage(公司覆盖)信息管理
- Sector(行业分类)管理(两级结构)
- Region(地区)管理
- 报告模板文件管理(Word/Excel)

**报告管理模块:**
- 报告创建(基本信息 + Word 文档 + Excel 模型文件)
- 报告编辑(基本信息和文件)
- 版本管理(所有修改保留历史,记录修改人和时间)
- 报告发布(标记为已发布状态,记录发布时间)
- 报告拒绝(软删除)
- 未发布报告列表查看

**对外接口:**
- 提供已发布报告的查询 API,支持按时间戳增量查询,供外部系统集成

## Capabilities

### New Capabilities
- `基础数据管理`: 管理分析师、公司覆盖、行业分类、地区等基础数据
- `报告创建`: 创建新的研究报告,关联基础数据和上传文件
- `报告编辑`: 修改报告基本信息和文件
- `版本管理`: 追溯报告的所有修改历史,支持合规检查
- `报告发布流程`: 控制报告的发布和拒绝状态

## Impact

**数据库结构:**
- 新增 Analyst、Coverage、Sector、Region 表
- 新增 Template 表(报告模板 Word/Excel)
- 新增 Report、ReportVersion、ReportFile 表

**后端 API:**
- FastAPI 服务,提供基础数据和报告管理的 RESTful API
- 集成 Supabase 认证和存储

**开发工具:**
- 使用 uv 作为统一的包管理和项目工具链
- 后端 Python 项目使用 uv 管理依赖、虚拟环境和脚本运行
- 提供极致的依赖安装和脚本执行速度

**前端界面:**
- Vue 单页应用,采用桌面式界面设计
- 界面语言: 英文 (所有 UI 文本、标签、按钮均使用英文)
- 桌面环境:功能卡片分组显示(报告功能组 + 基础数据管理组)
- 窗口化操作:所有功能以可拖动、可调整大小的窗口形式呈现
- 报告管理窗口:报告列表、创建报告、编辑报告、报告模板管理
- 基础数据管理窗口:Analyst、Coverage、Sector、Region 管理
- 数据内容:支持中文(报告标题、摘要、分析师姓名等业务数据可使用中文)
