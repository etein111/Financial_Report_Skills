# insights/

从实践中积累的洞察和经验。定期审阅，成熟后提炼进 `principles/`。

## 约定

### 总结经验

当用户说"总结经验"时，把当前 session 的工作提炼为通用原则，写入本目录下的独立文件。

**触发词**：`总结经验`、`整理原则`

**流程**：

1. 回顾当前 session 完成的工作
2. 提炼其中可复用的通用原则（不是记录做了什么，而是归纳下次怎么做得更好）
3. 按关注点拆分，每个文件一个主题
4. 写入 `insights/` 目录，格式参考 `doc-organization.md`

**不写什么**：具体操作步骤、临时状态、一次性决策。

**与 `principles/` 的关系**：`insights/` 是草稿区，定期审阅后成熟的规则提炼进 `principles/`，对应的 insight 文件删除。
